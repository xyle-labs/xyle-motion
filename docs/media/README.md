# Workflow demo provenance

`workflow.gif` is original documentation artwork generated by
[`scripts/demo.mjs`](../../scripts/demo.mjs) from the installed Xyle Motion
package. The script, YAML scenes, Xyle Crosspoint logo, example SVGs, music and
effects are Xyle Motion originals under MIT. No third-party screenshots,
recordings, client content, personal paths or credentials appear in the demo.
Generation and review instructions are in [the workflow guide](../workflow.md).

The 28.51-second GIF is 800 × 450 at 8 fps, loops, and contains no audio. Five
illustrated steps summarize verified CLI commands; the final six seconds show
the real rendered example. Timing is condensed. This is not a terminal recording
or evidence of autonomous agent performance. The text quickstart provides the
same workflow without animation.

Review on 1 November 2026 covered the before/after frame, all five steps at
three moments each, browser playback of the walkthrough/result, GIF decoding,
dimensions, duration, file size and metadata. The GIF has no metadata tags or
audio stream. The optional generated MP4 retains the example's music/effects;
listening acceptance is not claimed. The GIF's reviewed bytes are pinned in
`scripts/reviewed-media.json`; other binary documentation files remain blocked.
